Cómo publicar tus cambios
  1. Agrega o edita tus productos aquí. Las fotos se reducen solas.
  2. La web se publica sola ~10 segundos después de cada cambio (la primera vez pegas tu token en el formulario de abajo; queda guardado solo en este navegador).
  3. GitHub Pages la actualiza en ~1 minuto. No hace falta exportar nada.

Sin internet a mano, la alternativa sigue siendo: Exportar web (.zip) → copia el contenido a la carpeta de la web → git push.
